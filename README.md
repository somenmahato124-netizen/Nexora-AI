# 🤖 Nexora AI

> A modern, intelligent AI assistant powered by Google's Gemini API.

Nexora AI is a premium full-stack AI chatbot designed to help users **learn, code, create, analyze documents, generate images, and explore ideas** through a clean and responsive chat interface.

Built with **Node.js, Express.js, JavaScript, HTML, CSS, and Google Gemini AI**.

---

## ✨ Features

### 💬 AI Chat
- Ask questions and get AI-powered responses
- Natural conversational interface
- Supports Markdown-style formatting
- Code block rendering
- Copy response functionality
- Copy code functionality

### 💻 Programming Assistance
Nexora AI can help with:

- Python
- Java
- C / C++
- JavaScript
- HTML / CSS
- SQL
- PHP
- React
- Data Science
- Machine Learning
- Algorithms & DSA
